# The strokes are those of a classic one-stroke handheld alphabet, traced by hand from its public reference chart
# (cited in docs/dev/reports/039-strokes-s1.md): start point, direction, loops, corners and retraces as the chart
# draws them, one template per glyph (the chart shows one way to write each). The coordinates are our own drawings
# in our own format; no file, image or data of the alphabet's owner is used or copied. A few letters also have the
# natural variants people write without the chart (b and v, after the first test on the board; report 041
# section 12): each glyph's first line is the chart's stroke.
#
# Letters type lower case; a shift gesture before a letter makes it upper case, two make caps lock. X takes two
# strokes, as in the chart: the extended prefix (a line down-right), then a line down-left (glyph x of the ext set).
# The chart's multiplication sign has the same two strokes as X; X wins and the sign has no stroke.
#
# Columns (whitespace-separated):  id  set  out  [gates]  template
#   set       letters | digits | punct (after a tap) | ext (after the extended prefix, a line down-right) |
#             any (a gesture of the letters and digits boxes; after a prefix only backspace counts, it leaves it)
#   out       a character, U+XXXX, KEY_SPACE | KEY_BACKSPACE | KEY_ENTER | KEY_TAB,
#             MODE_SHIFT | MODE_CAPS | MODE_PUNCT | MODE_EXT, ACCENT_GRAVE | ACCENT_ACUTE | ACCENT_CIRCUMFLEX |
#             ACCENT_TILDE | ACCENT_DIAERESIS | ACCENT_RING (a dead accent for the next letter)
#   gates     start=<cells> end=<cells> line=<dir|no|any> closed=yes|no|any turn=cw|ccw corners=N[-M] dirs=<numpad>
#             sharp=DEG[-DEG] (the sharpest turn over three of the 32 points, degrees: a V point against a U)
#             cells: tl tc tr ml mc mr bl bc br, rows t m b, columns l c r, * (all); unset gates come from the template
#   template  x,y points (0..100 on the longer side, y down; only the shape counts), or the word tap
# Several lines with the same id and set are variants of one glyph (the best variant counts).
