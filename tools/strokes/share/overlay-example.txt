# Example of a Strokes user overlay (tools/strokes/README.md, "User overlay"). Same format as glyphs.txt; it is read
# after the shipped table (in S3: ~/.config/applaunch/strokes-user.txt). Every line either adds a variant to a glyph,
# or follows a replace / remove directive. The whole file is refused if one line is wrong, and the shipped table then
# stays as it is.

# 1. One more way to write v: a rounded bottom and no flick to the right at the top (the shipped v stays too; the
#    best variant counts).
v      letters  v              start=tl end=tr corners=0-3   0,0 30,85 50,100 70,85 100,0

# 2. My own k: replace the shipped variant (the loop) by an angle bracket (lines written by the S6 training screen
#    look like this one).
replace k letters
k      letters  k              start=tr end=br               100,0 10,45 0,50 10,55 100,100

# 3. I never type the pound sign: remove it, so a stroke like it is rejected instead of typed.
remove pound ext
