## Tooling issues (for the owner of deck.py)

- `deck.py sudo` puts the password on the remote command line (`echo '<pw>' | sudo -S ...`), so a quoting error in the command, or `ps`, prints it. It happened once to me in a tool result (a shell syntax error echoed the command) and once through `ps`; I did not write it to any file or to this report. Consider rotating the password if those tool logs are kept, and feeding sudo through stdin instead.
- `deck.py put` with a Git Bash path such as `/tmp/x` is rewritten by MSYS to `C:/.../Temp/x`; use `MSYS_NO_PATHCONV=1`.
