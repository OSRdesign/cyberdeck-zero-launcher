### Defects found
1. **Del never removes** (FAIL). `meshcore.cpp:1064` compares the LVGL key with `KEY_DELETE` (111), but the launcher's `cp0_keyboard_lvgl_input.c:77` delivers Delete as `LV_KEY_DEL` (127). Same on the real board (`65_del_real.png`). The footer advertises "Del: remove channel". Fix: test `LV_KEY_DEL` (or handle the raw code in `handle_raw_key`). So channel removal works only by touching Remove, and the keyboard-only user cannot remove a channel.
2. **On-screen keyboard is cut off** (FAIL for touch entry). In every editor (`09b_compose_typed.png`, `11_compose_again.png`, `16_add_prompt.png`, `33_freq_edit.png`) the keyboard starts at logical y of about 122 and only its first two rows are inside the 320x170 window; rows 3 and 4 (z x c v b n m, space, symbols) are hidden behind the launcher's toolbar. In number mode only `1 2 3 4 5 6` and the mode/OK keys show: `7 8 9 0 .` cannot be tapped, so a frequency cannot be typed by touch. A hardware keyboard works. The code places the keyboard at y=42 below the header with height `kContentH-kHeaderH-42`, the picture shows it about 40 px lower than that: check the layout (probably the editor box offset).
3. **Copyright**: the "Credits" paragraph has no `Files:` (section 1).

Cosmetic (not blocking): tab labels cut ("Chat...", "Setti..."), Radio line cut after "22 ..." (dBm), hint lines cut ("Plug the MeshCore board into the USB ..."), "unsaved chan..." on the Save row, titles "Frequency ..." and error "#eu868 is already on t...". Contact "Heard" shows e.g. "157 d" for all old contacts on the real board (their stored times come from the board's clock, which was apparently months behind until the app's SET_TIME; the board clock now equals the deck's).
